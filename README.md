# 🌱 FunGro App

FunGro is a modern web application designed to provide a clean, user-friendly, and interactive experience. The application combines a beautiful frontend with backend functionality to create a professional full-stack web project.

## 🚀 Features

* 🔐 User Login & Registration
* 👤 User Authentication
* 📊 Interactive Dashboard
* 🔍 Easy Navigation
* 📱 Responsive Design
* 🎨 Modern & Attractive UI
* 🗄️ Database Integration
* 🔄 Frontend & Backend Integration
* ⚡ Fast and Smooth User Experience
* 🛠️ REST API Support

## ⚙️ Installation & Setup

### 1. Clone the Repository

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
cd fungro
```

### 2. Install Frontend Dependencies

```bash
npm install
```

### 3. Start the Development Server

```bash
npm run dev
```

Then open:

```text
http://localhost:5173
```

### 4. Backend Setup

Create and activate a virtual environment:

```bash
python -m venv venv
```

For Windows PowerShell:

```powershell
venv\Scripts\Activate.ps1
```

Install Python dependencies:

```bash
pip install -r requirements.txt
```

Run the Flask backend:

```bash
python app.py
```
